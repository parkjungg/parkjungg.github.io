## 지원 동기

26년 2월에 졸업을 앞두고, 마냥 취준 공부랑 알바만 하기엔 좀 아쉬워서 대외활동을 하려던 참에 메토링 4기 공고가 올라왔다.

본인은 메이플스토리를 예전부터 오래해왔고, 최근에도 한 적이 있어서 이번 캠프에 참여하면 더 뜻깊을 것이라 생각했다(지금은 사정상..안하는중 😯)

특히 지원 자격? 으로 메이플스토리, 메이플스토리M, 메이플스토리 월드를 플레이해본 경험이 있는 사람이 있다. 왜냐하면 최종 과제가 메이플과 관련된 실제 문제들을 해결해보는 기회가 주어지기 때문이다. 그래서 조금이라도 해본 사람이 좀 좋을 것이다..

또, 현직자 커리어 멘토링을 통해서 포트폴리오 피드백을 받고, 수정 및 보완을 하고 싶은 마음이 컸다. 그리고 취업 준비를 어떻게 하면 좋을지에 대해서도 조언을 받고 싶었다.

그런 마음에 이 캠프는 나와 매우 잘 맞을 것 같아서 지원을 바로 하였다.



## 자기소개서 작성

사실 공고를 조금 늦게봐서 지원을 늦게 하였다. 그것도 그거지만 미루고 미루다보니... 19일 마감인데 18일에 자소서를 모두 작성하고 19일에 서류를 제출하였다.(다음부턴 좀 미리미리...하자😂)

쨋든 서류 제출에는 기본 정보, 재학증명서 등 여러 항목이 있고 그 중에서도 제일 중요한 것은 바로 '자기소개서'이다.

메토링 4기에는 이전과 마찬가지로 총 3문항의 질문들이 있었고, 질문의 내용들은 비슷하지만 이전과 조금씩 달랐다.

**** 질문 문항 ****

1. 지원 동기 및 얻어가고 싶은 것
2. 팀 프로젝트 경험
3. 게임 업계에 관심을 가지게 된 이유와 직무에 대한 역량을 키우기 위한 노력


이렇게 총 3문항이였고, 본인은 이전에도 작성했던 경험을 살리고, 다른 회사 인턴 지원할 때 썼던 자소서를 참고해서 작성하였다.

자소서를 작성할 때, 뭔가 글자수를 거의 맞춰서 작성하는게 좋다고 생각하는 편이여서 최대한 근접하게 썼다.(800자이내면 750자이렇게?)

그리고 지원 동기 같은 경우에는 나의 게임 업계를 향한 진심과, 이를 위해 노력한 경험들을 글자수에 맞춰 쓸 수 있는만큼 서술하였다.

아무래도 이렇게 면접없이 서류만 보는 것은 자기소개서가 매우매우 중요하기 때문에 깊은 고민을 하면서 작성을 하고 수정하였다.


## 포트폴리오

사실 자기소개서 말고도 중요한 부분이 포트폴리오라고 생각한다.

제출할 때는 '선택'으로 되어있어 제출해도 그만, 안해도 그만인 것 같지만 무조건 제출해야하는 항목이다.

포트폴리오는 자신의 경험을 담아 남들에게 보여줄 수 있는 수단이기 때문에 자소서만큼 중요하기 때문에 꼭 제출하는 것을 추천한다.

본인은 포트폴리오를 pdf로 정리하여 제출하였는데, 사실 포트폴리오를 정리하긴 했지만 부족하다고 생각하는 부분이 많아 약간 불안했다.

그렇지만 시간도 없고, 제출은 해야하는 상황이었기에 급한대로 최근에 마친 프로젝트만 정리한 후 제출하였다.

포트폴리오 같은 경우에는 정답이 없기에 더욱 어떻게 구성해야할지 고민되는 것 같다.

<script>
document.addEventListener("DOMContentLoaded", function() {
  const images = Array.from(document.querySelectorAll("img[src^='/assets/img/2/']"));
  const modal = document.getElementById("lightbox-modal");
  const modalImg = document.getElementById("lightbox-image");
  const closeBtn = document.getElementById("close-btn");
  const prevBtn = document.getElementById("prev-btn");
  const nextBtn = document.getElementById("next-btn");

  let currentIndex = 0;

  function showImage(index) {
    currentIndex = index;
    modalImg.src = images[currentIndex].src;
    modal.style.display = "flex";
  }

  images.forEach((img, index) => {
    img.style.cursor = "zoom-in";
    img.addEventListener("click", function(e) {
      e.preventDefault();
      showImage(index);
    });
  });

  closeBtn.onclick = () => modal.style.display = "none";

  prevBtn.onclick = () => {
    currentIndex = (currentIndex - 1 + images.length) % images.length;
    showImage(currentIndex);
  };

  nextBtn.onclick = () => {
    currentIndex = (currentIndex + 1) % images.length;
    showImage(currentIndex);
  };

  modal.onclick = (e) => {
    if (e.target === modal) modal.style.display = "none";
  };
});
</script>
