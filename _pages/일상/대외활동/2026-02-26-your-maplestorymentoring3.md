# 3일차(2월 8일)


## 본격적 과제 시작

2일차와 동일하게 9시까지 모인 후, 전날 했던 활동들에 대한 리뷰를 해보는 시간으로 시작했다.

대부분 참가자들이 1:N, 1:1 멘토링 활동에 대해 긍정적인 리뷰를 해주었고, 나 또한 해당 활동이 매우매우 만족스러웠다 👍

리뷰 활동을 간단히 마치고, 다시 최종 과제를 팀마다 진행하였다.

우리 팀은 전날에 긴 회의 끝에도 주제를 선정하지 못해, 오후 12시까지는 최종적으로 주제를 선정하기로 결정하였다.

주제에 대해 각자의 의견을 한 사람씩 이야기 하며 어떻게 해야할지 정하기로 했고, 그 과정에서 PPT로 기획서를 작성하여 의견을 설득하신 분도 있었다.(그 사이에 그걸 만드시다니 대단하십니다..😯)

쨋든 각자 다른 의견도 존재했지만 최종적으로 하나의 주제를 선정하는데 성공했고, 각자 어떤 업무를 할지 정한 후 바로 작업에 들어갔다.

본인은 프로그래머지만, 프로토타입 제작에는 크게 관여를 하지는 않았다.

프로토타입 자체가 그렇게 큰 스케일은 아니였고, 프로그래머 한명이 전체적으로 담당해서 하는 것이 버전관리나 제작하는 데에 더 나을 것이라 판단되어 그렇게 하기로 결정!!

그래서 난 같은 프로그래머의 프로토타입 제작의 보조만 맡기로 하고, 제작에 필요한 디자인을 AI 이미지로 뽑아주었다(feat. Gemini 🍌)

그리고, 메이플스토리에 대해 어느정도는 알고 있기에 BM요소에 대해서 조사를 병행하며 프로토타입 제작을 도왔다.

## 참여 후기
 
이번에 진행 했던 메이플 대학생 게임 커리어 캠프는 내가 처음 게임업계를 진로를 생각하고 진행했던 첫 대외활동이었다.
그래서 처음이라는 생각에 많은 긴장과 설렘을 안고 시작했었고..
3박 4일이라는 짧은 시간 동안 내가 어떤 성장을 이룰 수 있을지, 이런 활동들이 과연 어떤 의미가 있을지 수 많은 고민들을 하게 된 시간이었던 것 같다.

<script>
document.addEventListener("DOMContentLoaded", function() {
  const images = Array.from(document.querySelectorAll("img[src^='/assets/img/6/']"));
  const modal = document.getElementById("lightbox-modal");
  const modalImg = document.getElementById("lightbox-image");
  const closeBtn = document.getElementById("close-btn");
  const prevBtn = document.getElementById("prev-btn");
  const nextBtn = document.getElementById("next-btn");

  let currentIndex = 0;

  function showImage(index) {
    currentIndex = index;
    modalImg.src = images[currentIndex].src;
    modal.style.display = "flex";
  }

  images.forEach((img, index) => {
    img.style.cursor = "zoom-in";
    img.addEventListener("click", function(e) {
      e.preventDefault();
      showImage(index);
    });
  });

  closeBtn.onclick = () => modal.style.display = "none";

  prevBtn.onclick = () => {
    currentIndex = (currentIndex - 1 + images.length) % images.length;
    showImage(currentIndex);
  };

  nextBtn.onclick = () => {
    currentIndex = (currentIndex + 1) % images.length;
    showImage(currentIndex);
  };

  modal.onclick = (e) => {
    if (e.target === modal) modal.style.display = "none";
  };
});
</script>
