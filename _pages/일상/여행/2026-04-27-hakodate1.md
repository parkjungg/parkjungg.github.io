그래서 작성하게된 하코다테 여행기✈️!!

하코다테를 내 블로그 첫 여행기로 남기려고 한다🔥

----------------------------------------

사실 하코다테 여행 자체는 완전 갑작스럽게 시작했다 😯

졸업하고 한번은 가려했는데 개인 일정과 알바 스케줄 때문에 가지 못하였다...🥲

그런데 마침 3주 동안 쉴 수 있는 기간이 주어져서(계약만료이슈?) 이때 아니면 갈 수 없다고 생각해서 조금씩 찾아보았다

몇 개월전부터 계획을 세웠던 것도 아니고, 가고싶다는 생각만 하다가 타이밍도 적절하고, 뱅기 티켓 가격이 생각보다 안비싸서 가기 1주일전에 예약을 때려버렸다.

비행기 티켓뿐만아니라, 숙박, 교통 패스등 미리 예약해야하는 것도 거의 하루 이틀전에 다 끝냈던 것 같다.

그래서 갑작스럽게 가는지라 여행 계획도 큼직하게만 잡고 바로 떠나기로 확정!!



## 1일차

홋카이도 여행은 이번에 3번째인데, 하코다테는 처음으로 가보는 것이였다.

처음에는 단순히 별모양 공원이 있다해서 흥미가 갔었는데, 더 찾아보니 세계 3대 야경, 수도원, 역사가 넘치는? 골동품 가게등 여러 관광 명소가 많아서 더욱 가고 싶었는데 이번 기회에 가게 되었다.

그리고 가장 큰 이유는,,, 단순히 ***눈***이 좋아서 선택하게되었던 것 같다(겨울이 좋아❄️)

암튼 하코다테는 인천에서 출발하는 직항편이 하루에 단 한번 있기에 오후 비행기를 타고 떠났다.(2시 출발)

<script>
document.addEventListener("DOMContentLoaded", function() {
  const images = Array.from(document.querySelectorAll("img[src^='/assets/img/16/']"));
  const modal = document.getElementById("lightbox-modal");
  const modalImg = document.getElementById("lightbox-image");
  const closeBtn = document.getElementById("close-btn");
  const prevBtn = document.getElementById("prev-btn");
  const nextBtn = document.getElementById("next-btn");

  let currentIndex = 0;

  function showImage(index) {
    currentIndex = index;
    modalImg.src = images[currentIndex].src;
    modal.style.display = "flex";
  }

  images.forEach((img, index) => {
    img.style.cursor = "zoom-in";
    img.addEventListener("click", function(e) {
      e.preventDefault();
      showImage(index);
    });
  });

  closeBtn.onclick = () => modal.style.display = "none";

  prevBtn.onclick = () => {
    currentIndex = (currentIndex - 1 + images.length) % images.length;
    showImage(currentIndex);
  };

  nextBtn.onclick = () => {
    currentIndex = (currentIndex + 1) % images.length;
    showImage(currentIndex);
  };

  modal.onclick = (e) => {
    if (e.target === modal) modal.style.display = "none";
  };
});
</script>
