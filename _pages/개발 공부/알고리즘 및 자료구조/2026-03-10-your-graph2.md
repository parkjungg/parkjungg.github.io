## 맵과 방향벡터

코딩테스트 문제를 풀다보면, 좌표계가 주어지고 해당 지점에 값을 찾는 문제들이 나온다(자주)

이를 해결하기 위한 방법으로 배열로 맵을 만들고, 상하좌우(필요하면 대각방향까지)의 방향을 정의하여 문제를 해결할 수 있다

기본적으로 direction y, x를 정의하고 이를 활용하면 된다.

```cpp
const int dy[] = {-1, 0, 1, 0};
const int dx[] = {0, 1, 0, -1};
int x = 0, y = 0;
for(int i = 0; i < 4; i++) {
	ny = y + dy[i];
	nx = x + dx[i];
}
```

기본적인 틀은 위와 같다.

next y, x를 4번(상하좌우)동안 모두 확인하여 갈 수 있는 곳인지 확인하는 방식이다.

```cpp
if(ny < 0 || ny >= n || nx < 0 || nx >= n) continue;
if(a[ny][nx] == 0) continue;
if(visited[ny][nx]) continue;
```
그런데 위 코드처럼 제한 사항을 **반드시** 걸어줘야한다
그렇지 않으면 갈 수 없는 곳을 가버려서 오류가 뜰 수도 있다...😂(맵 밖으로 나가버리기)

## DFS(Depth First Search) 깊이 우선 탐색

매우매우 자주 쓰이는 알고리즘으로 말그대로 **깊이**을 우선하여 탐색하는 알고리즘이다.

정의를 보자면..

**어떤 노드부터 시작해 인접한 노드들을 재귀적으로 방문하며 방문한 정점은 다시 방문하지 않으며 각 분기마다 가능한 가장 멀리 있는 노드까지 탐색하는 알고리즘**

탐색하는 방식은 다음과 같다

1. 어떠한 정점 u의 visited(방문했는지 체크하는 배열)를 참으로 바꾸고 u로부터 연결되어 있는 v지점을 탐색
2. 이때 방문되어있지 않은 노드에 대해 **재귀적**으로 DFS를 호출

구현하는 방식은 두 가지가 있다

1.방문했는지 **먼저** 확인

```cpp
void DFS(int here){
	visited[here] = 1;
	for(int there : adj[here]){
		if(visited[there]) continue;
		DFS(there);
	}
}
```

2.일단 이동 후 방문했는지 확인

```cpp
void DFS(int here){
	if(visited[here]) return;
	visited[here] = 1;
	for(int there : adj[here]){
		DFS(there);
	}
}
```

## BFS(Breadth First Search) 너비 우선 탐색

DFS와 다르게 BFS는 노드로부터 근처에 있는 노드부터 탐색하는 알고리즘이다.

정의는 다음과 같다

**어떤 정점에서 시작해 다음 깊이의 정점으로 이동하기전 현재 깊이의 모든 정점을 탐색하며 방문한 정점은 다시 방문하지 않는 알고리즘**

BFS는 보통 최단거리 알고리즘으로 많이 사용한다.

단, 중요한점은 **가중치**가 모두 같을 때만 가능하다!!

가중치가 같지않으면 다익스트라, 벨만 포드등의 알고리즘을 사용해야한다(추후에 알아보자)

구현은 큐(Queue)를 통해서 할 수 있다

```cpp
void BFS(int here){
	queue<int> q;
	visited[here] = 1; // 방문 처리
	q.push(here);
	while(q.size()){
		int here = q.front();
		q.pop();
		for(int there : adj[here]){
			if(visited[there]) continue;
			visited[there] = visited[here] + 1; // 최단거리 계산
			q.push(there);
		}
	}
}
```

### DFS와 BFS의 비교

DFS는 BFS에 비해 메모리를 덜쓰고, 코드가 더 짧으며(큐를 사용하지 않아서) 노드 전체를 탐색할 때 많이 사용한다

BFS는 가중치가 같은 그래프내에서 최단거리를 구할 때 사용한다



## 트리 순회

트리 순회란, 트리 구조에서 각각의 노드를 **한 번**만 방문하는 과정을 말한다.

트리 순회에는 세 가지 종류의 순회가 있는데 **후위, 전위, 중위** 가 있다

a. 후위 순회

**자식들 노드를 먼저 방문하고 자신의 노드를 방문**

이 말은, 노드의 자식 중에서 왼쪽을 먼저, 그 다음으로 오른쪽, 그리고 자신을 방문한다는 뜻이다

```cpp
void postOrder(int here){
	if(visited[here] == 0) { // 방문을 안했다면
		if(adj[here].size() == 1) // 자식이 하나라면
			postOrder(adj[here][0]);
		if(adj[here].size() == 2) { // 자식이 둘이라면
			postOrder(adj[here][0]); // 왼쪽 먼저
			postOrder(adj[here][1]);
		}
		visited[here] = 1;
		cout << here << ' ';
	}
}
```

b. 전위 순회

**자신의 노드를 먼저 방문하고, 자식들 노드들을 방문**

전위 순회는 자신의 노드를 먼저 방문하고, 그 다음 왼쪽, 오른쪽 순으로 탐색을 한다.


```cpp
void preOrder(int here) {
	if(visited[here] == 0){
		visited[here] = 1; // 자신 방문 처리 먼저
		cout << here << ' ';
		if(adj[here].size() == 1)
			preOrder(adj[here][0]);
		if(adj[here].size() == 2){
			preOrder(adj[here][0]);
			preOrder(adj[here][1]);
		}
	}
}
```

c. 중위 순회

**왼쪽 노드를 방문한 후 자신 노드를 방문하고 오른쪽 노드를 방문**

중위 순회는 왼쪽 → 자신 → 오른쪽 순으로 탐색을 진행한다. 


```cpp
void inOrder(int here){
	if(visited[here] == 0){
		if(adj[here].size() == 1){
			inOrder(adj[here][0]);
			visited[here] = 1;
			cout << here << ' ';
		}else if(adj[here].size() == 2){
			inOrder(adj[here][0]);
			visited[here] = 1;
			cout << here << ' ';
			inOrder(adj[here][1]);
		}else{
			visited[here] = 1;
			cout << here << ' ';
		}
	}
}
```
