## 1. 시간복잡도

**시간복잡도란?**

**입력크기에 대해 어떠한 알고리즘이 실행되는데 걸리는 시간이며 주요 로직의 반복횟수를 중점으로 측정한 것**

정의로 보면 무슨 소린지 감이 안잡힐 수 있다..

그러니깐 예를 들어 아래와 같은 코드가 있다고 하자

```for(int i = 1; i <= n; i++)
   {	
   	  cnt++;
   }```
   
이 코드의 주요 로직은 0부터 n까지 cnt를 1씩 증가시키는 것이다.
즉, n번의 cnt++ 코드가 반복되는 것이다.

이렇게 해당 코드가 실행되는데 걸리는 시간은 n이고 이를 다음으로 볼 빅오 표기법으로 나타낼 수 있다.

### 빅오 표기법

**- 복잡도에 가장 영향을 많이 끼치는 항의 상수인자를 빼고 나머지 항을 없애서 복잡도를 나타내는 표기법**

위의 예시를 빅오표기법으로 나타내면 `O(n)`으로 나타낼 수 있다.

여기서 가장 영향을 많이 끼치는 항의 상수인자를 빼고 나머지 항을 없앤다는 것이 무슨말이냐면...

예를 들어 어떤 코드의 반복이 `2*n^2 - n`이라고 하자.

여기서 n을 아무리 빼도 n^2에 큰 영향을 미치지 않는다. n이 10만이라면, 10만의 제곱에서 10만을 빼도 큰 티가 나지 않는다.

천만개의 상자가 있다고 했을 때 하나정도 없어도 겉으로 보기엔 티가 나지않는다는 것이다.(비유가 이게 맞나?)

쨋든 여기서 빅오표기법으로 표기한다면 n을 제외하고, n^2의 상수인자도 제외한 `O(n^2)이 `2*n^2 - n`의 빅오표기법으로 나타낸 것이다.

이는 가급적 외운다면 추후 코딩테스트에서 시간을 줄이는데 큰 도움이 될 것이다.

### 자료구조의 시간복잡도

- 배열(Array) - 
참조 : O(1)
탐색 : O(n)

- 배열(vector) -
참조 : O(1)
탐색 : O(n)
맨 끝, 앞에 삽입/삭제 : O(1)
중간에 삽입/삭제 : O(n)

- 연결리스트 -
참조 : O(n)
탐색 : O(n)
삽입/삭제 : O(1)

- 스택,큐 -
n번째 참조 : O(n)
가장 앞부분 참조 : O(1)
탐색 : O(n)
삽입/삭제 : O(1)

- 맵 -
참조 : O(logn)
탐색 : O(logn)
삽입/삭제 : O(logn)


## 2. 공간복잡도

**공간복잡도란??**

**입력크기에 대해 어떠한 알고리즘이 실행되는데 필요한 메모리 공간의 양**

컴퓨터 사양마다, 사용되는 메모리의 양이 모두 다르다. 또한, 매번 실행할때마다 사용되는 메모리의 양도 모두 다르다.

`int a[1000000];`

이렇게 선언된 배열이 있다면 해당 공간만큼 메모리를 할당할 것이다.

보통 int 타입 배열을 기준으로 보면, 3천만까지 배열을 선언할 수 있다.(128MB)
